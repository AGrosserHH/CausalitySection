Define the comparison.
Then inspect the evidence.

The reviewed-comparison panel makes treatment values, outcome coding, target population and adjustment choices explicit. It supports learning and hypothesis exploration, not operational decisions.

Installation matters: this page describes the reviewed-comparison feature of the aitiolin source. The code must be installed and its integration tests checked before publishing these capabilities as available in your copy. It is not a hosted demo or a claim of deployment.

What exactly is being compared?

For a categorical treatment, select two actual levels, such as month-to-month versus one-year contracts. Other levels are excluded and counted. For a continuous treatment, select two fixed doses within the overall observed range. Overall range checks alone do not establish conditional overlap.

Choose the event coded as 1 for a binary outcome. A risk difference of −0.05 means five percentage points lower probability, not a five-percent relative reduction. This number is an interpretation example, not a result from aitiolin.

ATE averages over the eligible analyzed sample; ATT targets treated observations; ATC targets controls. Continuous treatment is restricted to regression ATE between two fixed doses in this version.

Nominal covariates are one-hot encoded with a reviewed reference category inside the statistical model. The graph still contains the original variables. Missing selected values stop the analysis unless complete-case exclusion was explicitly chosen. Earlier cleaning remains part of the recorded assumptions.

All inferential methods here assume independent observations. This path does not provide cluster/panel inference, IV or front-door extensions, causal forests, doubly robust estimation or automatic choice of a true graph. Existing legacy controls remain separate.

Read comparability before the headline number

Overlap

Propensity distributions and empirical common ranges reveal whether the two groups have comparable support. Extreme scores are warnings, not an invitation to silently extrapolate.

Balance and weights

Standardized differences use the unadjusted pooled within-group standard deviation. After-adjustment balance and effective sample sizes are shown for matching and weighting.

Assumptions

The sufficient backdoor check is conditional on the saved DAG. Hidden confounders, timing errors, selection and misspecified statistical models can still invalidate an interpretation.

No warning does not prove positivity. Passed diagnostics do not establish causation. Reported confidence intervals do not account for uncertainty in the graph or all data-cleaning choices.

Record, compare and restore

Each successful reviewed comparison has a name, specification, data hashes, encoding, result and environment record. Use the workspace exports for JSON or ZIP. Dataset rows are not attached; names, annotations and statistical results can still be sensitive.

Restore without overwriting an analysis

Load matching raw data, select a bundle that contains a reviewed comparison and preview. Raw and replayed-cleaning hashes must match. Confirmation creates a new owned graph without estimating. Free-text edge evidence is not restored. Review the restored settings before running again.

ZIPs are read as bounded data, never extracted or executed. Checksums establish internal consistency, not the identity of the bundle author. Exports without a reviewed comparison cannot be restored through this route.

Compare specifications, not truth scores

Named runs show what changed in settings and the graph. A numerical difference is withheld when the treatment, outcome, event, target, data or analyzed sample do not match. A more stable coefficient does not by itself make a graph correct.

Local processing and privacy

The Django server processes and stores data. Processing is local only when you run that server on your own computer. This path makes no provider requests. Workspace session ownership, expiry, deletion and export limitations still apply; closing a tab alone does not delete server files.

Two small teaching datasets

Synthetic campaign: the specified data-generating process has an eight-percentage-point purchase-probability effect. Sampling variation means fitted results will not be exactly eight points.

Poor-overlap stress test: the generating model has a coefficient of 1.5, but treatment is completely determined by a covariate. This illustrates why a known formula and a fitted coefficient are not substitutes for observational overlap.

Both are artificial data, not recommendations about real customers. The existing Churn and World Bank walkthroughs remain educational examples with their original timing, aggregation and specification caveats.
